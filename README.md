# MY DOSO — GitHub Pages Website

A responsive static landing page for MY DOSO by Dosani Labs.

## Publish with GitHub Pages
1. Create or open the `my-doso` repository in the `dosanilabs` GitHub account.
2. Upload the contents of this folder to the repository root (keep the `assets` folder structure).
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at `https://dosanilabs.github.io/my-doso/` (if the repository is named `my-doso`).

## Included
- `index.html` — landing page
- `privacy.html` — draft privacy overview (review and replace with final legal policy before public launch)
- `styles.css`, `script.js`
- `assets/mascot/` — original MY DOSO mascot artwork
- `assets/screenshots/` — the two actual app screenshots supplied for the website

No build step or framework is required. The site is static HTML, CSS and JavaScript.
